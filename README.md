# Stock Market Analysis Project

## Overview
This project analyzes historical stock price data of Apple (AAPL), Microsoft (MSFT),
Netflix (NFLX), and Google (GOOG) over the past three months.

The objective is to study price trends, moving averages, volatility, trading volume,
and correlation between different stocks using data analytics techniques.

## Dataset
- Historical stock price data
- Time period: Last 3 months
- Companies: AAPL, MSFT, NFLX, GOOG

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- VS Code

## Analysis Performed
- Stock price trend analysis
- Moving average calculation
- Volatility analysis
- Trading volume analysis
- Correlation analysis

## Files in This Repository
- `stock_market.ipynb` – Complete analysis notebook

## Conclusion
This project demonstrates practical data analytics skills in financial market analysis
using real-world stock market data.
